# CP03 information architecture

The application home leads to Play (four existing modes), Explore (world, continent, country scopes), Progress (honest empty state), Help, and Settings (dialog). The header persists through the existing game. Mode cards carry the chosen type into the existing scope → setup flow; unavailable combinations show a notice. Home continent shortcuts are generated from `MAPS` and counts are data-derived. North and South America map failures and partial data are disclosed. Country search filters existing entries only. Progress/achievements are not fabricated or persisted. No future competitive features are presented as playable.

The legacy setup, challenge settings, game, win/loss and review screens remain. The visual layer uses CP02 tokens; no dataset or scoring logic was replaced. Country and continent screens retain their underlying controls and receive incremental restyling, rather than a wholly new selection engine.
