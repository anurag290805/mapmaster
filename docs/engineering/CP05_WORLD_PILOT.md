# CP05 isolated world-map pilot

This is an eight-country **development fixture**, not the playable world map and not CP05 acceptance. With `npm run dev`, open `http://127.0.0.1:5173/pilot/` (or the port printed by Vite). The `pilot/` directory is not an entry point or copied asset in the production build. The existing world and regional SVGs, game modes and CP04 score/session logic were not changed. Production-preview tests check that the fixture page is absent.

## Fixture identity and scope

The selected records were first checked against the existing reconciliation ledger; none is marked ambiguous or policy-dependent there. Each was then checked against [UN M49's ISO-alpha3 country/area list](https://unstats.un.org/unsd/methodology/m49/), the explicit Natural Earth Admin-0 feature ID, ISO-alpha2/alpha3 and feature class, GEOS validity, and an independently sourced GeoNames location inside both source and rendered simplified geometry. These checks substantiate the selected mapping and a representative location; they do **not** independently survey every boundary or establish political-policy approval. The pilot's default boundary representation is Natural Earth's de facto representation, not an adopted product policy.

The fixture includes large countries, small island countries, multipart countries and six continental regions. The game uses the name Cabo Verde in its world pool and Cape Verde in Africa; the fixture uses Cabo Verde, with the ISO code and feature ID rather than a global alias establishing the association. All **186 other configured world questions** are excluded, individually listed with their existing status and reason in `pilot/manifest.json`: 157 had a preliminary reconciled status, 22 were policy-dependent and seven ambiguous. Fiji was initially considered but excluded because [GeoNames Suva](https://www.geonames.org/2198148/suva.html) lies approximately 0.013 degrees outside its source geometry; this discrepancy is not resolved by guessing a new polygon. Disputed and policy-dependent records are not promoted into this fixture. All subnational scopes remain outside it.

## Source, assets and reproducibility

The source is [Natural Earth 1:10m Admin-0 countries 5.1.1](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/), ZIP SHA-256 `ce1ac7036499a0edd641fbc093cd209a98f96a49d2eca8480aaacad35138a7f6`. [Natural Earth's terms](https://www.naturalearthdata.com/about/terms-of-use/) state its data are public domain and attribution is not required. GeoNames landmark coordinates are credited to [GeoNames](https://www.geonames.org/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the Lisbon anchor is rounded to three decimals. UN M49 is used for identifier corroboration, not as boundary validation.

`pilot/map.svg` SHA-256 `1fca8886d6536f8f705259376d6a9cdf8e7e5a42c43e05cd1f645ee7e00c2483` contains 623 separately identified polygon paths in eight logical country groups. Every path in a group carries the same canonical entity ID, and no DOM IDs repeat. The manifest records each source NE_ID, source name, landmark, license and parts. The generator `tools/generate-world-pilot.py` checks the downloaded archive's SHA-256, source identities, source and simplified/rounded geometry validity and anchor containment. It simplifies with topology preservation at 0.005 degrees and rounds coordinates to four decimals; source and rendered polygon part counts match for each fixture country. Run with `PYTHONPATH=<temporary pyshp/shapely directory> python3 tools/generate-world-pilot.py <source-directory>`. A repeat generation with the same dependencies and sources reproduced identical SVG bytes. The rounded, simplified fixture is not authoritative: coastal shape, small islands, holes and border alignment can differ from high-resolution reality.

## Interaction and lifecycle

The dev harness provides fixed country names on keyboard-focusable SVG groups, a separate country chooser with submit, and a live feedback region. Accessible names describe each geography consistently and do not change based on the correct target. The chooser shares the same exact-canonical-ID scoring rule as pointer and keyboard activation. A focus-selected-country control zooms to the largest component; this improves pointer access to tiny targets while the chooser remains available if a shape is too small or obscured.

Zoom is clamped from 1× to 5×; buttons, wheel, drag panning, directional pan buttons and reset operate on the SVG transform. The drag threshold prevents a drag from being submitted as an answer. The page includes touch-emulated tap support; pinch is not implemented. No physical-device, screen-reader, comprehensive WCAG, geodetic survey or memory-safety claim is made. No zoom or pan logic was added to the live game.

Each reload advances a generation, associates the map and listener closures with that generation, and aborts the previous listener set when the new SVG installs. An obsolete request cannot install its map after a newer request, and old listener callbacks cannot score in the current session. A controlled browser test deliberately changes the owner guard to always accept: the held older response then overwrites the later map; with the guard intact it does not. This tests the pilot's protection, **not** the historical I-15 root cause or complete protection of the existing game's lifecycle.

## Verification and performance — 2026-11-01

- Targeted Brave pilot matrix: **8 passed, 0 failed, 10 skipped**. The six development tests include mouse hit testing on all eight countries, two distinct Canada polygon parts, wrong and repeated answers, keyboard activation, keyboard chooser submission and focus, touch-emulated Canada tap, 320/390px viewport checks, drag, wheel, directional pan, zoom boundaries and reset. The two preview projects each run the production-isolation check; five interaction tests per preview are intentionally skipped because the fixture is not shipped there. The development interaction test observed no browser console or page errors after the favicon fix.
- The stale-listener test dispatches an event to a detached former map after replacement and confirms it cannot score. A second test holds an earlier SVG response, installs a later response, and observes both response callbacks. With the generation guard intact the later map remains; with the guard deliberately replaced in the test the older map overwrites it. This is a deterministic pilot-specific failure demonstration, not proof of historical I-15. Five additional replacements retained one current SVG and rejected events sent to five prior nodes; this is limited cleanup evidence, not a memory-leak audit.
- The first full matrix found two preview-isolation test timeouts (108 passed, 2 failed, 10 skipped). The test had waited for the SPA fallback page's full load event; it was corrected to inspect the built directory and directly request the fixture page, script, manifest and SVG. A subsequent targeted run found a missing favicon 404 (7 passed, 1 failed, 10 skipped); the pilot now links the existing project icon. Both issues were retested without filtering console errors or adding arbitrary waits.
- Final `node tools/audit-data.cjs`: exit 0. `npm run check`: exit 0; **46 Node and 3 Vitest tests passed**, no failures or skips; typecheck, lint, format and build passed. `node --check` also passed for the pilot modules, which are outside the configured ESLint scope. Final Brave matrix: **110 passed, 0 failed, 10 skipped** across development, production preview and `/mapmaster/`; preview checks confirmed that `dist/pilot` and pilot responses are absent. The existing four modes remain covered by their retained regression tests, not exhaustively proven in every possible session.
- Performance: one local development sample measured 239 ms from navigation to observed readiness and five replacements at 188, 91, 102, 98 and 83 ms. Six Playwright zoom/pan button actions took 199 ms in total. These wall-clock figures include browser/test and local scheduling overhead under four-worker contention. The SVG is 902,887 bytes uncompressed. They are not a production-network, frame-rate, long-run memory or physical-device benchmark.
- Deterministic rebuild: SHA-256 for both `map.svg` and `manifest.json` was unchanged by regeneration with the same pinned source and inspection dependencies. `git diff --check` passed. The pilot is suitable for independent review with the stated geography, input and device limitations; CP05 remains unaccepted.

## Full-world diagnostic continuation (2026-11-01)

The prior eight-country pilot is development-accepted only. Its actual pointer, keyboard, chooser, touch-emulated, viewport and lifecycle findings above do not automatically apply to the separate 194-entity diagnostic SVG. `candidate/world.svg` and `candidate/world-manifest.json` are isolated diagnostic artifacts, not a game mode or an approved candidate for live gameplay. All 194 game identities are present; the exact 64 source-only context features are listed in the manifest and cannot score. The complete list of 194 records, identity evidence, source associations, outstanding policy flags and per-record blockers is in `CP05_WORLD_COVERAGE.json`.

All 194 are presently unsupported for *new candidate gameplay*: 186 have identifier corroboration only and eight have independent pilot checks rather than full candidate approval. Every record still needs a candidate-specific geographic and interaction review. A source feature is not proof that all of its boundaries are correct. Tiny states and island groups need reachable pointer targets or an equivalent chooser and focus/zoom path; the 50m and 10m sources differ materially for Seychelles, Maldives, Kiribati, Marshall Islands, Tuvalu, Monaco and Vatican City. These differences require review, not a silent mixture of map scales. The map does not itself implement keyboard, chooser, zoom or scoring.

## Separate 194-country harness (2026-11-01)

The original eight-country fixture and tests are preserved. `pilot/world/` is a second development-only harness for the unchanged diagnostic SVG and manifest; its per-input, lifecycle, performance and geographic limitations are reported in `CP05_WORLD_CANDIDATE_VALIDATION.md` and `CP05_VERIFICATION.md`. Its ability to select a canonical record does not validate the corresponding geographic shape, disputed border, sovereignty status or suitability for live scoring.
