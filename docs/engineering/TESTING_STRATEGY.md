# Testing strategy

- `npm test`: ten existing CP02/CP03 Node tests plus the Vitest unit suite.
- `npm run test:legacy`, `npm run test:unit`: run the suites independently.
- `npm run test:e2e`: builds **separate** root (`dist-e2e-root`) and `/mapmaster/` (`dist-e2e-subpath`) preview artifacts before Playwright starts Vite dev and both previews. This prevents a subpath build from overwriting the root artifact. The normal matrix intentionally skips the Firebase cloud tests unless the explicit emulator environment is present. Install a browser with `npx playwright install chromium`, or set `MAPMASTER_BROWSER_PATH` to a compatible Chromium-family executable. Tests isolate their browser context and abort external HTTPS requests; they do not clear the user's existing browser storage.
- `npm run test:e2e:emulator`: starts only local Auth and Firestore emulators, runs the four local Auth/Rules tests and five browser cloud-sync tests, and supplies a fixed `mapmaster-local-acceptance` synthetic web configuration plus emulator hosts explicitly. It does not inherit `.env.local` or select a real project. Use it for cloud-sync evidence; do not run those browser tests against a live Firebase configuration.
- `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run check`: new TypeScript, tests and config are the initial quality scope. Legacy JS remains covered by Node tests and `node --check`, not a wholesale formatting rewrite. `check` excludes E2E because browsers and local listeners are environment-dependent.

Smoke tests do not prove full gameplay, accessibility or map hit-testing. Known data and map defects are not silently marked passing. Run `node tools/audit-data.cjs` and `python3 tools/audit-svg.py` separately; the former intentionally exits nonzero for two existing missing paths.
