# Build and release

`npm ci` installs from the lockfile; `npm run dev` serves source, `npm run build` creates static `dist/`, and `npm run preview` serves it locally. The production output includes the game HTML, bundled CSS and TS module, the classic game scripts, SVG map files and brand assets; the showcase and development documents/tests are excluded. Vite transforms some directly referenced SVGs and preserves dynamically selected map URLs via copied `svg/`. The America paths remain broken as documented. Never serve the raw source as a release.

Version 0.3.5 is a private local checkpoint identifier, not a published release. For any later release: run the quality gate and browser tests, audit dependencies and licenses, verify map/data correctness, perform accessibility and device testing, review the resulting static files and hosting base path, then obtain deployment authorization. Roll back a future release by restoring the previously verified immutable artifact; no deployment exists here. No secrets or environment configuration are required by this local app; never place secrets in client-side environment variables. No CI, hosting or production environment was created.
