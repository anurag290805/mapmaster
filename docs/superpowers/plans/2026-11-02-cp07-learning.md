# CP07 Geography Content & Learning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add provenance-safe answer feedback and accessible missed-answer review using the existing game engine.

**Architecture:** A small stateless formatter in the existing shared gameplay module builds a learning record from game-supplied prompt/answer values. Legacy UI renders the record after answers and the existing review mode pages through `missedRegions`; `gameState` remains the sole session store.

**Tech Stack:** Vanilla browser JavaScript, TypeScript shared gameplay bridge, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-02-cp07-learning-design.md`
