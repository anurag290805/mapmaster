# Accessibility

Target WCAG 2.2 AA; this checkpoint is not a conformance audit. Shared focus-visible styling, 44px minimum game buttons, labeled answer input, polite game feedback, semantic form controls, native dialog, tab arrow keys, focus restoration and reduced-motion CSS provide a foundation. Showcase feedback uses text symbols as well as color; its live region announces a toast. Help text is available through a touch- and keyboard-operable disclosure.

Brave verification covered dialog Escape/focus restoration and tab keyboard focus, not a screen-reader audit. Contrast ratios, focus visibility in every legacy selector, target dimensions across all controls, reduced-motion rendering and text resizing have not been exhaustively checked. Existing SVG map keyboard accessibility I-07 remains for CP05/11; do not represent locate mode as accessible without an alternative. Legacy animations and JavaScript timers still exist; CSS reduced-motion does not eliminate all runtime work. Existing icon buttons still rely partly on title text. Complete manual and assistive-technology testing in CP11.

## Follow-up evidence and limitations

Brave: Space toggled the native card; disabled example remained disabled. Enter opened the help disclosure and Escape closed it. The notification announced a status and returned focus after dismissal. Earlier dialog Escape/focus-return and tab arrow behavior were exercised. The game input's duplicated `aria-label` was removed. Selected token pairs were calculated using WCAG relative luminance: light text/surface 14.54:1, light primary/white 6.81:1, dark text/surface 13.02:1, dark primary/ink 9.47:1, error on raised surface 5.81:1 light and 7.06:1 dark. These are selected pairs, not a complete contrast audit. A new dark-theme legacy primary-button foreground issue was observed and corrected; computed retry colors are `#102824` on `#8ed9bb` (9.47:1). No assistive-technology, complete Tab/Shift+Tab sequence, touch-target audit, reduced-motion device emulation or full text scaling audit was completed. Map accessibility remains I-07 for CP05/11. No WCAG conformance is claimed.
