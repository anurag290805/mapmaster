# MapMaster design system — CP02

The direction is contemporary atlas: quiet parchment and deep ink surfaces, explorer teal for actions, and restrained clay for emphasis. The map remains the primary subject. System sans and monospace typography require no network or purchased font. Legacy `variables.css` remains for existing selectors; `tokens.css` introduces semantic `--mm-*` tokens and `integration.css` bridges common legacy variables. Stylesheet order in `index.html` is legacy CSS, tokens, components, integration. `components.css` is namespaced `.mm-*` except focus and reduced-motion rules. No game rule or dataset is changed.

Light remains the default, matching the legacy policy. `body.dark-theme` supplies dark tokens; existing `mapmaster-theme` dark/light persistence remains unchanged. The showcase theme is a separate in-memory preview and never writes player settings. The current game still reads localStorage after body creation, so first-paint flash and denied-storage behavior remain unresolved. The existing game still loads Twemoji flag images from a CDN; CP02 removes the Poppins web-font import, not flag CDN use.

Tokens include semantic canvas, surface, raised, text, brand, accent, line, focus, success/error/warning/info, spacing, widths, control size, radii, shadow, duration/easing and layers. Legacy selectors and hardcoded map/game colors remain; this is incremental tokenization, not a complete conversion. Components should consume semantic tokens, not raw palette values. Original artwork colors are fixed in SVG.

Follow-up: theme read and writes now catch storage exceptions, retaining light fallback on unreadable storage and in-memory toggling on unwritable storage; invalid values retain the existing light default. These paths are source-inspected, not browser-simulated. Legacy primary buttons now use dark ink on the pale dark-theme brand background. No gameplay state or rules changed. `design-system.html` is deliberately public if deployed as a static file and identifies its data as examples.

## Approved future palette (CP05 decision)

The approved future MapMaster palette is Dark Charcoal `#1A1A1A`, Electric Cobalt Blue `#1558C9`, and Lime Green `#32CD32`. Charcoal surfaces should use a subtle grain texture; cobalt and lime communicate Earth's oceans and land. These are the approved future design tokens and supersede earlier conflicting palette guidance. CP05 uses them only within the development-only candidate controls; an accessible, contrast-reviewed application across the existing UI is deferred to a dedicated visual-system checkpoint rather than bundled into the map integration.
